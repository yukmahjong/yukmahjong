🔧 Firebase Setup
One-time setup for multiplayer rooms
Step 1: Go to console.firebase.google.com and sign in with Google.
Step 2: Click Add project, name it (e.g. "yukmahjong"), complete the wizard.
Step 3: In your project go to Build → Realtime Database → Create database. Choose a region, start in test mode.
